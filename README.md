DS2 Tank Viewer & Packer
A native C# .NET 8.0 utility for Dungeon Siege 2.
DS2 Tank Editor is a tool designed to help modders inspect, extract, and create .ds2res .ds2map
(Tank) files for Dungeon Siege 2. Whether you are looking to explore existing game archives or create your own custom content, this utility provides a streamlined workflow to handle DS2 resource containers.
